| Model | Parameters | Detections | Confidence | Latency |

## 🔑 KEY INSIGHTS

### Architecture Selection
1. **Text**: BiLSTM lebih cocok (sequential processing lebih efisien)
2. **Vision**: CNN lebih cocok untuk small images (local features penting)
3. **Detection**: Model size trade-off linear dengan latency

### Performance Trade-offs
- Text: +0.60% accuracy = +183% training time (Transformer vs BiLSTM)
- Vision: +23.87% accuracy = +53% training time (CNN vs ViT)
- Detection: 2.0× parameter increase = 2.0× latency increase

### Speed-Accuracy Pareto Front
| Task | Fast | Balanced | Accurate |
|------|------|----------|----------|
| Text | BiLSTM 42s | BiLSTM 42s | BiLSTM 42s |
| Vision | ViT 60s | CNN 92s | CNN 92s |
| Detection | YOLOv8n 52ms | YOLOv8s 62ms | YOLOv8m 104ms |
