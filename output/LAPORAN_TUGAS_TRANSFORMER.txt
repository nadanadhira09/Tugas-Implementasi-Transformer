1. DATASET
═════════════════════════════════════════════════════════════════════════════════

1.a) Text Classification
─────────────────────────────────────────────────────────────────────────────
Menggunakan dataset AG News (berita Bahasa Inggris) yang terdiri dari 120,000 
sampel training dan 7,600 sampel testing dengan 4 kelas:
  • World (berita dunia)
  • Sports (olahraga)
  • Business (bisnis)
  • Sci/Tech (sains dan teknologi)

Teks dipotong pada panjang sekuens maksimal 256 token (lebih panjang dari template
karena hasil menunjukkan model dapat handle lebih banyak context). Vocabulary size
diatur pada 5,002 tokens dengan simple tokenization (lowercase + punctuation removal).

1.b) Vision Classification
─────────────────────────────────────────────────────────────────────────────
Menggunakan dataset CIFAR-10 yang beresolusi 32×32 pixel dengan 3 kanal warna (RGB)
dan terdiri dari 10 kelas objek:
  • Airplane, Automobile, Bird, Cat, Deer, Dog, Frog, Horse, Ship, Truck

Dataset terdiri dari 50,000 sampel training dan 10,000 sampel testing. Dilakukan 
data augmentation pada training set (RandomHorizontalFlip, RandomRotation, ColorJitter)
dan normalisasi dengan CIFAR-10 mean dan std.

1.c) Non-Klasifikasi (GitHub)
─────────────────────────────────────────────────────────────────────────────
Menggunakan model YOLOv8 Nano untuk object detection dengan sampel input gambar 
jalan raya (bus.jpg) beresolusi 640×480 pixel. Task ini mendemonstrasikan aplikasi
real-world dari pre-trained models dengan hyperparameter modification.


2. MODEL ARCHITECTURE
═════════════════════════════════════════════════════════════════════════════════

2.a) Text Transformer (Custom Implementation)
─────────────────────────────────────────────────────────────────────────────
Arsitektur diimplementasikan from scratch dengan layer-layer:
  • Embedding Layer: vocab_size=5002 → embed_dim=128
  • Positional Encoding: Sinusoidal encoding dengan fixed positions
  • Transformer Encoder: 2 layers dengan 8 attention heads
  • Global Average Pooling: Menggabungkan representation semua tokens
  • Linear Classifier: Hidden→4 classes (softmax)

Keunggulan: Parallelization memungkinkan training yang cepat meskipun dengan 
sequence length 256 tokens. Self-attention mechanism mampu menangkap long-range
dependencies antar kata.

2.b) Text BiLSTM with Attention (Baseline)
─────────────────────────────────────────────────────────────────────────────
Arsitektur sequential dengan layer-layer:
  • Embedding Layer: vocab_size=5002 → embed_dim=128
  • BiLSTM: 2 layers, bidirectional dengan hidden_size=64
  • Custom Attention Mechanism: Query-Key-Value attention untuk context weighting
  • Linear Classifier: Hidden→4 classes (softmax)

Keunggulan: Lebih efisien parameter (847k vs 938k pada Transformer), training 
2.7× lebih cepat, convergence lebih baik (train loss 0.0858 vs 0.1964).

2.c) Vision Transformer (ViT) - Custom Implementation
─────────────────────────────────────────────────────────────────────────────
Arsitektur patch-based vision transformer dengan:
  • Patch Splitting: Memecah gambar 32×32 menjadi patches (4×4=64 patches atau 8×8=16 patches)
  • Patch Embedding: Linear projection patches ke embedding space (embed_dim=128)
  • Positional Embedding: Learnable positional embeddings untuk setiap patch
  • Class Token: Special token untuk classification (inspired by BERT)
  • Transformer Encoder: 2 layers dengan 8 attention heads
  • Classification Head: [CLS] token → 10 classes

Keunggulan pada large-scale vision tasks. Kelemahan: Memerlukan dataset massive
untuk pembelajaran inductive bias spasial dari nol.

2.d) Vision CNN with Residual Blocks (Baseline)
─────────────────────────────────────────────────────────────────────────────
Convolutional neural network dengan advanced components:
  • Initial Conv: 3 input channels → 64 filters (3×3 kernel)
  • Residual Layer 1: 64→64 channels (2 blocks) dengan skip connection
  • Residual Layer 2: 64→128 channels (2 blocks) dengan downsampling
  • Residual Layer 3: 128→256 channels (2 blocks) dengan downsampling
  • Global Average Pooling: Spatial averaging untuk 256 features
  • FC Layer: 256 → 10 classes

Keunggulan: Built-in inductive bias (translation invariance, locality), sangat 
cocok untuk gambar kecil 32×32. BatchNormalization memastikan training stability.

2.e) YOLOv8 Nano (Object Detection)
─────────────────────────────────────────────────────────────────────────────
Menggunakan pre-trained YOLOv8 Nano model dari Ultralytics library. Model 
dimodifikasi dengan:
  • Confidence threshold: 0.25 → 0.85 (meningkatkan precision, menurunkan recall)
  • Default NMS IoU: 0.45 (unchanged)

Task: Object detection bukan klasifikasi karena model output multiple bounding boxes
dengan coordinate regression, bukan single class label.

Non-Klasifikasi Rationale:
YOLO melakukan simultaneous object localization dan classification:
  1. Regression: Prediksi coordinate bounding boxes (4 values: x,y,w,h)
  2. Classification: Prediksi class probability untuk setiap box
  3. Output: Multiple detections per image (bukan single class label)

Ini BUKAN task klasifikasi karena output bukan single class tapi multiple boxes
dengan spatial information (localization).

Modifikasi Impact:
Confidence threshold 0.25 → 0.85:
  • Precision: Meningkat ↑ (fewer false positives)
  • Recall: Menurun ↓ (lebih banyak false negatives)
  • Use case: Safety-critical applications yang prioritas accuracy over coverage


5. ANALISIS HASIL MENDALAM
═════════════════════════════════════════════════════════════════════════════════

5.1 Model Mana yang Paling Akurat?
─────────────────────────────────────────────────────────────────────────────
Domain Teks:
  • Transformer: 90.64% ← LEBIH TINGGI (winner)
  • BiLSTM: 90.47%

Domain Vision:
  • CNN: 85.06% ← DOMINAN (winner)
  • ViT: 62.36%

Kesimpulan: Task-dependent. Transformer sedikit lebih baik untuk text, CNN jauh 
lebih baik untuk small images.

5.2 Model Mana yang Paling Cepat?
─────────────────────────────────────────────────────────────────────────────
Text Domain:
  • BiLSTM: 43.96s total (8.79s/epoch) ← JAUH LEBIH CEPAT
  • Transformer: 120.06s total (24.01s/epoch)
  Speedup: 2.7× dengan BiLSTM

Vision Domain:
  • ViT (8×8): 47.13s total (9.43s/epoch) ← TERCEPAT
  • CNN: 88.30s total (17.66s/epoch)
  • ViT (4×4): 53.45s total (10.69s/epoch)
  Catatan: Speedup dengan larger patches tapi akurasi menurun drastis

5.3 Apakah Transformer Selalu Lebih Baik?
─────────────────────────────────────────────────────────────────────────────
TIDAK. Efektivitas Transformer bergantung pada:

1. DOMAIN APPLICABILITY:
   • Teks: Transformer UNGGUL (long-range dependencies, parallelization)
   • Gambar Kecil: CNN UNGGUL (inductive bias spasial, parameter efficiency)
   • Gambar Besar (ImageNet): Transformer UNGGUL (ViT outperforms CNN)

2. DATA SCALE:
   • Small dataset (CIFAR-10): CNN lebih baik (tidak perlu banyak data)
   • Large dataset (ImageNet, BERT corpus): Transformer lebih baik (leverage scale)

3. COMPUTATIONAL BUDGET:
   • Limited resources: BiLSTM/CNN lebih baik (2.7-5× lebih cepat)
   • High compute available: Transformer lebih baik (dapat memanfaatkan parallelization)

5.4 Mengapa CNN Masih Kuat untuk Gambar Kecil?
─────────────────────────────────────────────────────────────────────────────
CNN memiliki INDUCTIVE BIAS bawaan:

1. TRANSLATION INVARIANCE:
   Filter konvolusi yang sama berlaku di seluruh gambar, tidak peduli posisi
   object. Parameter weight-sharing sangat efisien untuk small images.

2. LOCALITY:
   Filter 3×3 hanya melihat neighboring pixels, cocok untuk texture dan edge
   detection pada resolusi 32×32.

3. FEATURE HIERARCHY:
   Layer pertama detect edges, layer middle detect shapes, layer akhir detect
   semantic features. Hierarchy ini perfect untuk vision.

SEBALIKNYA ViT:
  • Memandang patches sebagai "tokens acak" tanpa spatial structure
  • Memerlukan BANYAK data untuk belajar spatial relationships dari nol
  • Untuk CIFAR-10 (50k samples): UNDERFIT, hanya 62.36% accuracy

5.5 Mengapa BiLSTM Kompetitif dengan Transformer untuk Text?
─────────────────────────────────────────────────────────────────────────────
AG News characteristics:
  • Sequence length: Rata-rata 50-100 words (kami padding ke 256)
  • Vanishing gradient: Belum severe pada length ini
  • Konteks: Local context (nearby words) sudah cukup untuk classification

BiLSTM advantages:
  • Dirancang specifically untuk sequential data
  • Parameter sharing antar time steps sangat efisien
  • LSTM gates (input, forget, output) memiliki implicit regularization
  • 2.7× lebih cepat training

Transformer advantages:
  • Parallelization: Dapat process semua positions simultaneously
  • Long-range: Attention dapat capture any-to-any dependencies
  • Lebih powerful: Tapi overkill untuk task sederhana

Trade-off: BiLSTM = 90.47%, Transformer = 90.64%. Perbedaan 0.17% tidak signifikan.

5.6 Apa Kelemahan ViT pada Dataset Kecil?
─────────────────────────────────────────────────────────────────────────────
ViT Fundamental Limitation:

1. NO SPATIAL INDUCTIVE BIAS:
   Patch 4×4 diperlakukan sebagai "flat tokens" tanpa spatial structure.
   Attention tidak "tahu" bahwa patches yang berdekatan adalah neighbors.

2. REQUIRES MASSIVE DATA:
   ViT perlu learn spatial relationships dari scratch.
   ImageNet (1.2M images): ViT UNGGUL
   CIFAR-10 (50K images): ViT UNDERFIT

3. UNDERFITTING ON SMALL SCALE:
   Model terlalu "general" untuk small dataset dengan limited diversity.
   CNN lebih specific untuk vision → better prior knowledge.

Result: 62.36% accuracy, jauh di bawah CNN 85.06%.

5.7 Apa Pengaruh Patch Size pada ViT?
─────────────────────────────────────────────────────────────────────────────
Eksperimen Patch Size:

│ Patch Size  │ # Patches   │ Accuracy │ Train Time   │

│ 2×2         │ 256         │ 58.13%   │ 114.07s      │

Trade-off Analysis:
• Smaller patches (2×2): More detail (256 patches) tapi training overhead
• Medium patches (4×4): BEST BALANCE - good accuracy dengan reasonable speed
• Larger patches (8×8): Fastest tapi kehilangan fine-grained details

Fundamental Issue: Bahkan patch terbaik (4×4, 62.36%) masih jauh lebih rendah
dari CNN (85.06%) karena lack of spatial bias.

5.8 Pengaruh Sequence Length pada Text
─────────────────────────────────────────────────────────────────────────────
Kompleksitas Self-Attention: O(n²) terhadap sequence length

Kami menggunakan max_seq_len = 256 tokens:
  • Complexity: 256² = 65,536 attention comparisons per sample
  • Trade-off: Longer context vs computational cost
  • Result: Terbukti efektif untuk AG News (90%+ accuracy)

Jika max_seq_len = 64 (template default):
  • Complexity: 64² = 4,096 (16× lebih ringan)
  • Tradeoff: Kehilangan context, potentially lower accuracy

Jika max_seq_len = 512:
  • Complexity: 512² = 262,144 (16× lebih heavy)
  • Benefit: Lebih banyak context untuk long documents

Kami pilih 256 sebagai sweet spot untuk AG News.

5.9 Input/Output GitHub Non-Klasifikasi (YOLOv8)
─────────────────────────────────────────────────────────────────────────────
INPUT:
  • Format: Image file (JPG/PNG)
  • Resolusi: 640×480 pixels (dapat resize otomatis)
  • Channels: 3 (RGB)
  • Content: Gambar jalan raya dengan multiple objects

OUTPUT (untuk setiap detected object):
  • Bounding Box Coordinates: (x_center, y_center, width, height) dalam pixels
  • Confidence Score: 0.0 - 1.0 (probability object ada dalam box)
  • Class Label: String nama class (e.g., "car", "bus", "person")
  • Multiple detections: List of objects (bukan single classification)

Contoh output:
  {
    "detections": [
      {"class": "bus", "confidence": 0.95, "bbox": [320, 240, 200, 150]},
      {"class": "car", "confidence": 0.87, "bbox": [100, 200, 100, 80]},
      {"class": "person", "confidence": 0.92, "bbox": [50, 50, 30, 60]}
    ]
  }

5.10 Mengapa YOLOv8 Bukan Klasifikasi?
──────────────────────────────────────────────────────────────────────────────
Classification Output: Single label per image
  Input: Image
  Output: One class (e.g., "cat" atau "dog")
  Example: ImageNet classification

Object Detection Output: Multiple objects dengan lokasi
  Input: Image
  Output: List of (class, confidence, bbox) per detected object
  Example: YOLO, Faster R-CNN, SSD

YOLO melakukan SIMULTANEOUSLY:
  1. Regression: Prediksi bounding box coordinates
  2. Classification: Prediksi class untuk setiap box

Output adalah BUKAN single class, tapi multiple spatial-labeled detections.

5.11 Modifikasi Kode dan Pengaruhnya
──────────────────────────────────────────────────────────────────────────────
MODIFIKASI APPLIED:

YOLOv8 Default Parameters:
  • conf_threshold = 0.25 (confidence cutoff)
  • iou_threshold = 0.45 (NMS intersection-over-union)

MODIFIKASI:
  • conf_threshold: 0.25 → 0.85 (INCREASED significantly)
  • iou_threshold: 0.45 → unchanged (kept default)

CODE MODIFICATION:
  results = model.predict(image_path, conf=0.85)  # Default: conf=0.25

IMPACT ANALYSIS:

1. PRECISION MENINGKAT:
   Sebelum (conf=0.25): Banyak low-confidence detections (false positives)
   Sesudah (conf=0.85): Hanya high-confidence predictions (fewer false positives)

2. RECALL MENURUN:
   Sebelum: Menangkap semua objects (termasuk yang unlikely)
   Sesudah: Hanya yakin objects (kehilangan beberapa detections)

3. USE CASE:
   conf=0.85: Safety-critical (autonomous driving, medical imaging)
   conf=0.25: General purpose (surveillance, analytics)

ALTERNATIVE MODIFICATIONS (untuk riset):
  • NMS IoU threshold: 0.3 (loose), 0.45 (default), 0.6, 0.75 (strict)
    Effect: Mengontrol duplicate detections dari overlapping boxes

  • Confidence threshold: 0.5 (balanced), 0.7 (strict), 0.9 (very strict)
    Effect: Mengontrol false positive rate

Kami testing multiple NMS IoU values (0.3, 0.45, 0.6, 0.75) untuk comprehensive analysis.


6. KESIMPULAN
═════════════════════════════════════════════════════════════════════════════════

6.1 FINDINGS
────────────────────────────────────────────────────────────────────────────
✓ TEXT CLASSIFICATION (AG News):
  • Transformer (90.64%) SEDIKIT lebih akurat dari BiLSTM (90.47%)
  • Perbedaan MINIMAL: hanya 0.17% (praktis equivalent)
  • BiLSTM lebih SMART untuk production: 2.7× lebih cepat, parameter lebih sedikit
  • KESIMPULAN: Untuk task ini, BiLSTM adalah pilihan lebih pragmatik

✓ VISION CLASSIFICATION (CIFAR-10):
  • CNN (85.06%) DOMINAN mengungguli ViT (62.36%)
  • Perbedaan SIGNIFIKAN: 22.7% (CNN clear winner)
  • CNN inductive bias spatial perfect untuk small images
  • ViT butuh dataset massive (ImageNet) untuk shine
  • KESIMPULAN: CNN adalah pilihan yang tepat untuk CIFAR-10

✓ PATCH SIZE IMPACT:
  • Smaller patches (2×2): Lebih detail tapi training overhead
  • Balanced size (4×4): Best trade-off untuk CIFAR-10
  • Larger patches (8×8): Fastest tapi detail loss
  • KESIMPULAN: No patch size dapat mengatasi lack of spatial bias ViT

6.2 MAIN INSIGHTS
────────────────────────────────────────────────────────────────────────────
1. TRANSFORMER BUKAN ALWAYS WINNER:
   Efektivitas bergantung pada domain, data scale, dan computational budget.
   Tidak ada "one-size-fits-all" solution di deep learning.

2. INDUCTIVE BIAS MATTERS:
   CNN spatial bias (translation invariance, locality) CRUCIAL untuk small images.
   BiLSTM sequential bias SUFFICIENT untuk moderate-length text.
   Transformer requires large-scale data untuk learn bias dari nol.

3. EFFICIENCY TRADE-OFFS:
   Transformer unggul di accuracy untuk text (tapi perbedaan minimal)
   BiLSTM unggul di efficiency (2.7× speedup, fewer parameters)
   Untuk production systems: efficiency matters!

4. DATA SCALE CRITICAL:
   ViT underfitting pada CIFAR-10 (50k samples) → 62.36%
   ViT shining pada ImageNet (1.2M samples)
   Trade-off: Accuracy vs Data requirements

6.3 REKOMENDASI
────────────────────────────────────────────────────────────────────────────
Untuk TEXT CLASSIFICATION:
  • Use Transformer jika akurasi absolute paling penting
  • Use BiLSTM jika efficiency, speed, dan simplicity penting
  • Untuk AG News: BiLSTM adalah pilihan lebih baik (0.17% accuracy loss worth it)

Untuk VISION CLASSIFICATION (small images):
  • Use CNN (inductive bias sudah optimal)
  • Use ViT hanya untuk large-scale image data (>100k samples)
  • For CIFAR-10: CNN adalah pilihan clear-cut

Untuk OBJECT DETECTION:
  • Use YOLO family untuk real-time requirements
  • Adjust confidence threshold sesuai precision/recall requirements
  • Use higher conf threshold untuk safety-critical applications

6.4 FUTURE WORK
────────────────────────────────────────────────────────────────────────────
1. Training dengan LEBIH BANYAK EPOCHS untuk ViT (current 5 epoch mungkin underfitting)
2. Pre-training ViT pada ImageNet dann fine-tuning ke CIFAR-10
3. Hybrid architecture: Combine CNN early layers dengan Transformer
4. Knowledge distillation: Student ViT learns dari Teacher CNN
5. Data augmentation lebih aggressive untuk ViT
